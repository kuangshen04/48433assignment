# Retired regulatory analytics diagrams

These three diagrams describe the former independently operated Regulatory Analytics subsystem. They were retired on 2026-10-28 when that subsystem was removed from the 5k report and its working outline.

- `analytics-container.puml`
- `analytics-component.puml`
- `analytics-code.puml`

They are retained as historical design material, not as part of the current architecture. The active render script reads only `../../src/*.puml`. Legacy documentation pages and their existing analytics images may still describe the former proposal; the current report no longer references those images.

Regulator access to scoped queries, evidence requests, recall investigations and exports remains in the current platform. Ordinary insight projections also remain. The separate evidence mirror was subsequently removed when recovery was simplified to managed backups and participant-held proof exports. Historical diagrams on legacy pages are not the current report architecture.
